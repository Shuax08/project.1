Implemented endpoints include `/health`, `/s/<slug>`, `/s/<slug>/whatsapp`, `/api/auth/login`, `/api/auth/logout`, `/api/shops`, `/api/shops/me`, `/api/menu` (GET/POST), `/api/menu/<id>` (PATCH), `/api/customers` (GET/POST), `/api/customers/<id>` (GET), `/api/customers/<id>/credit` (GET/POST), `/api/orders` (POST), `/api/orders/<id>` (GET/PATCH), `/api/orders/<id>/receipt` (GET), `/api/orders/<id>/receipt.html` (GET), `/api/shops/me/printer` (GET/PATCH), `/api/reports` (GET), and `/webhooks/whatsapp` (GET/POST). Mutations after login require `X-CSRF-Token` from the login response. Signed Meta message webhooks resolve the shop by configured phone number ID and process customer text orders. Outbound delivery errors return 503 for retry.
